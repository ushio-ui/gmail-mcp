## 0. 結論（先に要点）

1. **技術的には十分に実現可能です。** MVP（試作品）は AI をほぼ使わず、「Vodca が決めた配色ルール」をデータ化するだけで作れます。費用も品質も安定します。
2. **事業としては「成立し得るが、当初の計画のままでは厳しい」と考えます。** 主な理由は次の3つです。
   - **月額5,000円は安すぎる可能性が高い**（外注IC費用と比べて価値に対して安く、逆に必要な顧客数が多くなりすぎる）。
   - **工務店は「自社の標準仕様（採用メーカー・品番）」の中でしか選べない**ため、汎用の商品データでは実務で使えない。各工務店の採用品リストを取り込む仕組みが必須。
   - **一般施主向け 4,980円の買い切りは、集客費用に対して単価が低く、単独では採算が合いにくい。**
3. **最大の差別化要素は「選択肢を減らすプロのルール」と「Vodca の監修ブランド」**です。カラーシミュレーターや仕様決めクラウドは既に存在しますが、「プロの審美眼で組み合わせを絞り込む」ことを主機能にしたサービスは、調べた範囲では目立ちません（ただし完全に存在しないとは断定できません）。
4. **一番の難所はプログラムではなく「データの整備と更新」**です。配色ルールの言語化、商品データの入力、メーカーの廃番対応に、継続的な人手がかかります。
5. **おすすめの進め方**：まず工務店 3〜5社に協力してもらい、「その会社の標準仕様 × Vodca ルール」で動く試作品を無料で使ってもらう。お金を払う意思があるか・いくらなら払うかを確かめてから本格開発に進む。

## STEP 1：事業・技術の実現可能性分析

### 1-1. 市場規模

**【事実】**
- 2025年の新設住宅着工は 74万667戸（前年比 6.5%減、3年連続減少、過去20年で最少）。そのうち**持家（主に注文住宅）は 20万1,285戸（前年比 7.7%減、4年連続減少）**。（[データ・マックス](https://data-max.co.jp/article/83436)、国交省 建築着工統計）
- 新築注文住宅の着工は、平成25年の約35.5万戸から令和6年には約21.8万戸へ約4割減少したとの分析がある。地方圏ほど減少が大きい。（[東急リバブル](https://www.livable.co.jp/fudosan-toushi/propertista/report/202604/index02.html)）
- 業界団体の規模感：全国中小建築工事業団体連合会（全建連）会員 約5万社・年間供給 約12万戸、JBN・全国工務店協会 会員 約3,000社・年間供給 約3万戸（2018年資料、団体間で重複あり）。（[国交省資料](https://www.mlit.go.jp/common/001260443.pdf)）
- 建設業許可業者は全国で約47.5万社（建設業全体の数で、工務店だけではない）。（[CREX](https://crexgroup.com/ja/home-building/service-other/national-construction-company-number-ranking/)）

**【推定】ターゲットになる工務店数**
- 「年数棟〜数十棟の新築住宅を建てる会社」に絞ると、全建連の5万社の多くは年0〜数棟の小規模事業者・大工さんで、色決めアプリに月額を払う可能性は低いと考えます。
- JBN 会員規模（約3,000社・平均約10棟/年）＋非会員の同規模工務店を合わせ、**現実的なターゲットは 5,000〜1万5,000社程度**と推定します（根拠は団体資料からの概算で、精度は高くありません）。
- このうち 3〜5年で獲得できるのは、一般的な中小企業向けSaaSの浸透率（数%）から考えて **数百社が現実的な目標**です。ご提示の「2,000社」は、ターゲットの13〜40%にあたり、かなり楽観的です。

**【推定】リフォーム市場**
- 新築は縮小傾向ですが、リフォーム・リノベーション会社、設計事務所、建売・分譲会社（標準カラーパターンの設定業務）は追加の市場になり得ます。

> ⚠️ **リスク**：主要ターゲットの新築注文住宅市場は毎年縮小しています。「新築工務店だけ」に依存しない計画が必要です。

### 1-2. 競合サービスと価格

調べた範囲で、競合は次の6種類に分けられます。

| 種類 | 例 | 価格 | Vodca案との関係 |
|---|---|---|---|
| ① メーカー公式のカラーシミュレーター | 主要建材・設備メーカー各社のWebシミュレーター（**【仮説】各社の提供状況は要確認**） | 無料 | 1社の商品だけ。メーカーをまたいだ調和は見てくれない。**「無料で色を試せる」機能自体には価値がつきにくい** |
| ② 住宅仕様決めクラウド | **egaku/エガク**（コムテックス、富山）＝仕様確定・カタログ・打ち合わせ資料作成を支援。工務店での導入事例あり（[newscast](https://newscast.jp/news/1504613)、[@Press](https://www.atpress.ne.jp/news/375201/print)） | 非公開（要問い合わせ） | **最も近い競合**。「仕様を決めて書類にする」業務効率化は既に提供されている。Vodca案は「デザインの良し悪し」で差をつける必要がある |
| ③ カラーセレクト系の提案ツール | 住宅販売会社向け「カラーセレクトシミュレーション」（iPad対応Webツール）（[value-press](https://www.value-press.com/pressrelease/128668)） | 非公開 | 「色を選んで画面で見せる」機能は既存 |
| ④ 住宅CAD・3Dプレゼンソフト | 住宅設計CAD（内観パース機能付き）、マイホームクラウド等 | 月数千円〜数万円 | 既に工務店が持っている場合が多い。画像シミュレーションで勝負するのは不利 |
| ⑤ 建材データベース | **Arch-LOG**（丸紅アークログ）＝約700社・180万点超の建材データ、横断検索・サンプル請求（[丸紅](https://www.marubeni.com/jp/news/2024/group/00003.html)） | 要確認 | 競合というより**データ連携の相手候補** |
| ⑥ 人による外注コーディネート・SNS・生成AI | 外部IC、Instagram/Pinterest、画像生成AI | IC：簡易相談1〜3万円、トータル10万円前後〜（[crowdworks](https://crowdworks.jp/times/know-how/8472/)） | 施主は無料のSNS・AIで「イメージ」は集められる。**ただし「実在する品番で、ちゃんと施工できる組み合わせ」までは出せない** |

**率直な指摘**
- 「色を選べる」「画面でシミュレーションできる」「仕様書を出せる」は、どれも**既に競合がある機能**です。これらを売りにすると価格競争になります。
- 競合各社の料金は非公開が多く、今回は確認できませんでした。**STEP 5 の前に、egaku 等に資料請求して機能・価格を比較することを強く推奨**します。

### 1-3. 差別化できる可能性

**【仮説】勝てる可能性があるポイント**
1. **「選択肢を減らす」こと自体が価値**：多くの競合は「全部の色を見せる」設計。Vodca案は「プロが合わないものを外す」設計。施主の迷いと打ち合わせ時間を減らせる。
2. **メーカー横断の調和**：メーカーシミュレーターは自社製品だけ。床（A社）× 建具（B社）× クロス（C社）の相性をみるのは、まさにICの仕事。
3. **プロ監修ブランド**：「Vodca 監修」という人とブランドへの信頼。ただし**現時点では全国的な知名度がないため、ブランド構築（施工事例・SNS発信）が並行して必要**。
4. **工務店の標準仕様に合わせた提案**：「その工務店で実際に採用できる品番の中で、一番きれいな組み合わせ」を出せれば、実務で使える数少ないツールになる。

**弱み・注意点**
- 配色ルールは特許などで守りにくい。大手が同様のルールを作れば真似される可能性がある。守れるのは「ルールの質」「継続的な更新」「ブランド」「工務店ごとのデータ蓄積」。
- ルールの質が代表者お一人の知見に依存している（属人性）。事業が大きくなるほどボトルネックになる。

### 1-4. 工務店が月額を払う合理性

**【推定】費用比較（年間10棟の工務店の場合）**

| 方法 | 年間コスト目安 |
|---|---|
| 外部ICへ委託（1棟 3〜10万円と仮定） | 30〜100万円 |
| 専任IC を雇用（年収350〜450万＋社会保険等と仮定） | 450〜600万円 |
| 営業担当が自分で色決め（打ち合わせ1棟あたり計10時間×時給3,000円と仮定） | 約30万円（＋品質のばらつき） |
| **本アプリ 月額5,000円** | **6万円** |

- 費用面では**月額5,000円は「払う合理性」が十分ある**（安すぎるくらい）。
- 一方で問題は**「本当に外注や打ち合わせ時間を減らせるか」を信じてもらえるか**です。工務店は新しいツールの導入に慎重で、「入れたけど使われない」ことが多い業界です（**【仮説】**、ヒアリングで要確認）。
- **月額5,000円の問題点**：安いことで売りやすくはなりますが、必要な顧客数が増え、営業・サポートの負担で赤字になりやすい（1-7参照）。**月額1〜3万円＋初期設定費**の方が事業として健全と考えます。

### 1-5. 一般施主向け買い切りの可能性

**【仮説】課題**
- 施主は、**自分の工務店が採用しているメーカー・品番の中からしか選べない**ことが多い。アプリが提案した品番が使えないと「結局使えなかった」となる。
- 1件4,980円で、ネット広告で1人獲得するのに数千円〜1万円以上かかることが一般的（**【推定】**）。**単価が低く、リピートもない**ため、広告で集める販売は採算が合いにくい。

**提案**
- 施主向けは「**無料のテイスト診断**（好みのテイストと配色イメージがわかる）」を入口にし、
  - 有料の「Vodca 監修プラン（3〜5万円）」や
  - 「お近くの提携工務店の紹介」
  につなげる**集客装置**として使う方が合理的です。
- もしくは**工務店が施主にアカウントを配る**形（工務店の契約に施主用の利用枠を含める）にすれば、施主は工務店の採用品番で選べて、Vodca は工務店から収益を得られます。

### 1-6. 工務店への効果的な営業・集客

**【仮説】有効そうな順**
1. **既存の取引先・紹介**：今お付き合いのある工務店に試作品を無料で使ってもらい、導入事例をつくる（最優先）。
2. **業界団体・勉強会**：JBN、地域工務店ネットワーク、FC本部、建材商社・建材店の工務店向けセミナーで登壇。
3. **建材商社・建材店との提携**：建材店は工務店と毎日接点がある。「建材店が工務店に配るツール」にできれば、営業効率が大きく上がる。
4. **業界紙・業界メディア**：新建ハウジング等への寄稿・広告。
5. **SNS・施工事例発信**：Instagram で「Vodca ルールでつくった空間」の発信。施主からの指名（「このアプリ使ってる工務店がいい」）を生めれば強い。
6. **無料トライアル（1〜3物件まで無料）**。

> 工務店向けは「Web広告だけで申し込んでくれる」ことは少なく、**説明・デモ・導入支援（人手）**が必要になると考えておくべきです。

### 1-7. 収益性と事業リスク

**【推定】月額5,000円で損益分岐する社数**

前提（すべて仮定）：
- 固定費 月150万円（データ整備・サポート担当1名、開発保守の外注、サーバー・各種ツール、広告・営業費）
- 決済手数料 約3.6%、サーバー費は顧客1社あたり月100〜300円程度

→ 1社あたりの粗利 約4,600円／月 → **損益分岐 約330社**。
→ 月額15,000円なら 約110社、月額25,000円なら 約65社。

**【推定】解約率の影響**
- 中小企業向けSaaSでは月2〜3%の解約は珍しくない。月3%解約の場合、平均利用期間は約33か月。
- 月5,000円 × 33か月 ≒ **1社あたり生涯売上 約16.5万円**。1社獲得に営業・デモで5〜10万円かかると、利益は小さい。

**【推定】ご提示の試算（工務店500社＋施主2,000件＝年4,000万円）について**
- 売上は計算上そのとおりですが、500社を獲得・維持するには、営業・サポートで2〜4名程度の人員が必要になる可能性が高く、人件費だけで年1,500〜2,500万円。データ更新費・開発保守費・広告費を含めると、**利益は出ても小さい／赤字の可能性もある**と考えます。

**主なリスク**
| リスク | 内容 | 対策案 |
|---|---|---|
| 市場縮小 | 新築注文住宅は年々減少 | リフォーム・分譲・設計事務所向けへ展開 |
| データ更新コスト | メーカーの廃番・新色が毎年発生 | 工務店ごとの採用品に絞る／廃番チェック機能／建材DB提携 |
| 利用許諾 | メーカー画像を無断利用できない | 当面は自社作成の色見本＋品番テキスト、提携後に画像 |
| 属人性 | ルールが代表者の知見に依存 | ルールを文書・データ化し、監修チームを育成 |
| 「使われない」 | 導入しても現場が使わない | 打ち合わせで実際に使う流れを設計、導入支援 |
| 価格競争 | 競合が類似機能を追加 | 品質・ブランド・工務店データの蓄積で差別化 |
| 責任範囲 | 提案した品番の施工不可・納まり問題 | 利用規約で「最終確認は工務店・専門家」と明記、品番に施工上の注意を表示 |

### 1-8. 技術面の分析

#### (1) 技術的に実現可能か
**はい。** MVP の機能（テイスト選択→床選択→建具・クロス提案→一覧→保存）は、一般的な Web アプリの技術で問題なく作れます。特殊な技術は不要です。

難しいのは次の2点です（プログラムよりも中身の問題）：
- **配色ルールを、コンピューターが判断できる形に言語化すること**
- **リアルな室内シミュレーション画像**（素材の質感・光の当たり方を正しく見せるのは、開発費が大きく、MVP では後回し推奨）

#### (2) AI を使うべき機能／ルールで十分な機能

| 機能 | 方法 | 理由 |
|---|---|---|
| テイストに合う床・建具・クロスの提案 | **ルール（AI不要）** | 結果が毎回同じで品質が安定。費用ほぼゼロ。Vodca の審美眼をそのまま反映できる |
| 相性の悪い組み合わせの除外 | **ルール** | 「なぜダメか」を説明できる |
| 一覧表・PDF出力・物件管理 | **通常のプログラム** | AI は不要 |
| 提案理由の文章（「この床には〇〇な理由でこの建具が合います」） | ルールごとに Vodca が説明文を用意（MVP）→ 将来 AI で言い換え | 最初は人が書いた方が質が高い |
| 施主の好みの写真からテイストを判定 | **AI（将来）** | 画像から雰囲気を読み取るのは AI が得意 |
| 室内イメージ画像の生成 | **AI（将来、要検証）** | 生成AIは実在品番の色・質感を正確に再現できない可能性が高い。「イメージ」と明示して使う |
| 新商品の自動分類（色・木目の数値化） | **AI補助＋人が確認（将来）** | データ入力の手間を減らす |

→ **MVP は AI を使わない構成を推奨します。** AI の利用料がかからず、「なぜこの提案なのか」をプロとして説明できることが、むしろ強みになります。

#### (3) 推奨システム構成（専門用語をなるべく使わない説明）

```
[ スマホ・タブレット・PC のブラウザ ]
            │  （インターネット）
            ▼
[ 画面とプログラム ]  …… Next.js（Webアプリを作る定番の道具）
   ホスティング：Vercel（置き場所。小規模なら無料〜月数千円）
            │
            ▼
[ データの保管庫 ]   …… Supabase（データベース＋ログイン機能。小規模なら無料〜月数千円）
   ・商品データ（床・建具・クロス…）
   ・配色ルール
   ・物件ごとの選択結果
            │
            ▼
[ 決済 ]  …… Stripe（クレジットカードの月額・買い切りを扱うサービス）
[ PDF出力 ] …… ブラウザ上で生成
```

- アプリはまず**ブラウザで動く Web アプリ**にし、スマホのホーム画面に追加できる形（PWA）にします。iPhoneアプリの審査や手数料が不要です。
- **配色ルールと商品データは、Vodca が Excel／Googleスプレッドシートで編集**し、それをアプリに取り込む方式にします。プログラムを触らずにルールを改善できます。

#### (4) Codex（AI開発ツール）でどこまで開発できるか

| 作業 | AI で可能か |
|---|---|
| 画面・ボタン・選択の流れの作成 | ◎ ほぼ可能 |
| データベース・ログイン・保存 | ◎ 可能（設定作業に人の操作が一部必要） |
| PDF出力 | ○ 可能 |
| 決済（Stripe）の組み込み | ○ 可能。ただし**本番前に専門家のチェック推奨** |
| 配色ルールの中身 | ✕ **Vodca にしかできない**（最重要） |
| 商品データの収集・入力・許諾 | ✕ 人の作業・交渉が必要 |
| 利用規約・特定商取引法の表記・プライバシーポリシー | △ 下書きは可能、最終確認は専門家 |
| セキュリティ・個人情報の安全確認 | △ 有料公開前に専門家のチェック推奨 |
| 洗練されたデザインの最終調整 | △ AI で形にし、Vodca の目で仕上げる |

→ **MVP 〜 工務店数社でのテスト版までは、AI 中心で十分に開発できます。** 有料販売を始める段階で、決済・セキュリティ部分のみ外部の技術者に確認を依頼するのが安全です。

#### (6) 配色ルールのデータ化方法

Vodca の頭の中にある判断を、次の3段階で表にします。

**① 商品に「特徴タグ」をつける**（1商品1行）

| 項目 | 例 |
|---|---|
| 部位 | 床 / 建具 / 巾木 / 壁クロス / 天井クロス / キッチン扉 … |
| 色の明るさ（明度） | 1（暗い）〜 10（明るい） |
| 色の系統 | 赤み / 黄み / ニュートラル / 青み（グレー寄り） |
| 鮮やかさ（彩度） | 低 / 中 / 高 |
| 素材感 | 木目 / 石目 / 単色 / 織物調 / 塗り壁調 … |
| 木の種類（木目の場合） | オーク / ウォールナット / チェリー / メープル … |
| 木目の強さ | 弱 / 中 / 強 |
| 艶 | マット / 半艶 / 艶あり |
| 合うテイスト | ナチュラル◎ / モダン○ / ジャパンディ◎ … |

**② 組み合わせのルールを書く**（例：これは仮のサンプルです）

| ルールの種類 | 例 |
|---|---|
| 除外（絶対NG） | 「床と建具で、異なる樹種の強い木目を組み合わせない」 |
| 除外 | 「赤みの床 × 青みのグレー建具は不可」 |
| 推奨条件 | 「ナチュラルでは、建具の明度は床と同等〜2段階明るく」 |
| 推奨条件 | 「モダンでは、巾木は建具または床と同色」 |
| 加点・減点 | 「壁クロスは床より明度が3以上高いと＋2点」 |

**③ 点数で並べる**
- 除外ルールに当たったものは候補から外す
- 残りに点数をつけ、**◎おすすめ（上位3つ程度）／○こちらも可／（ボタンを押すと）△個性的な選択** として表示
- 「選択肢を広げる」ボタンで ○ や △ まで表示 → **自由な表現を妨げない**

> この方式なら、Vodca が表を書き換えるだけでルールを改善できます。
> 最初は**ルール 20〜50 個、商品 各部位 10〜20 点**程度で十分です。

#### (7) メーカー品番データの管理方法

**取得方法の選択肢**
| 方法 | 長所 | 短所 |
|---|---|---|
| A. メーカーのカタログ・Webから手入力 | すぐ始められる | 手間が大きい。画像の利用は無許諾では不可 |
| B. メーカーと正式に提携しデータ提供を受ける | 画像も使える、正確 | 交渉に時間。実績がないと相手にされにくい |
| C. Arch-LOG 等の建材データベースと提携 | 複数メーカーをまとめて扱える | 条件・費用が不明（要問い合わせ） |
| D. **工務店から「自社採用品リスト」を受け取る** | 実務で本当に使う品番だけになる | 工務店ごとに整備の手間 |

**推奨**：**D を中心に、A で補い、事業実績ができたら B・C を交渉**。

**著作権・利用許諾の整理（一般論）**
- **商品名・色名・品番**のような事実情報そのものは、一般に著作権で保護されにくいとされます。ただし、メーカー Web サイトの利用規約でデータの転載・機械的な収集（スクレイピング）を禁止している場合があり、**規約違反のリスク**があります。
- **商品写真・カタログ画像・木目のテクスチャ画像**は著作物であり、**無断利用は不可**。
- **メーカー名・ロゴ**の使い方によっては商標・不正競争防止法の問題が生じうる（「〇〇社公認」と誤解させない）。
- → MVP では**架空の商品データ＋Vodca が作った色見本**で開発します（ご指示どおり）。

**廃番・新商品への対応**
- 各商品に「発売日」「廃番予定日」「状態（販売中／廃番予定／廃番）」を持たせる。
- 保存済み物件に廃番品が含まれる場合は警告を表示し、**ルールに基づいて代替品を自動提案**。
- メーカーの改廃は年1〜2回（春・秋の新カタログ時）に集中することが多いので（**【仮説】**）、その時期にまとめて更新する運用にする。

#### (8) サブスクリプションと買い切り決済の実装

- **Stripe**（世界的に使われるオンライン決済サービス）で、月額課金と買い切りの両方に対応できます。手数料は国内カード決済で約3.6%（**要最新確認**）。
- 必要な付帯作業：特定商取引法に基づく表記、利用規約、プライバシーポリシー、インボイス対応の領収書、解約・返金ルール。
- **MVP の段階では決済は作りません。** テスト期間は無料提供 or 請求書払いで十分です。

#### (9) 将来的な機能拡張

1. PDF 提案書・仕様書（工務店のロゴ入り）
2. 工務店ごとの採用品リスト登録・管理画面
3. 施主と工務店の共有リンク（施主がスマホで確認・コメント）
4. 写真合成による簡易カラーシミュレーション
5. AI による好み診断（写真から）
6. 外装（外壁・屋根・サッシ）、照明、カーテン、家具への拡張
7. 見積ソフト・発注システムとの連携
8. 建売・分譲会社向け「標準カラーパターン」作成機能

## STEP 2：アプリ設計の提案

### 2-1. 設計の基本方針

- **「選ぶ」のではなく「選ばれたものから選ぶ」**：最初の画面に出すのは最大3案。
- **1画面1つの質問**：迷わせない。
- **いつでも戻れる・変えられる**：床を変えたら、合わなくなった建具には自動で注意表示。
- **専門用語を使わない**：「明度」ではなく「明るめ／落ち着いた」。
- **美しい画面**：余白を大きく、色見本を大きく。Vodca のブランドらしい静かで上質な見た目。

### 2-2. 色決めの順番（Vodca の実務の順番）

アプリの進行は、Vodca が実際の打ち合わせで決めている順番に合わせます。

| 順 | 段階 | 主な部位 | 前の段階との関係 |
|---|---|---|---|
| 1 | 外回り | 外壁、屋根、サッシ（外観色・**内観色**）、玄関ドア、破風・軒天・雨樋 等 | サッシの内観色が室内の色の基準の一つになる |
| 2 | 床・建具 | フローリング、室内建具 | テイスト＋サッシ内観色と調和させる |
| 3 | 階段 | 段板、蹴込み、手すり、ささら | 床・建具に合わせる |
| 4 | クロス | 壁、天井、アクセントクロス | 床・建具・階段の組み合わせに合わせる |
| 5 | 細かい部材 | 巾木、笠木、窓枠、カウンター、見切り材、カーテンレール 等 | **原則「建具に合わせる／床に合わせる」を自動で初期設定し、確認だけにする** |
| 6 | 設備 | キッチン、浴室、洗面台、トイレ | ここまでの内装に合う扉色・天板・パネルを提案 |

設計上のポイント：
- **前の段階を変えると、後ろの段階に「合わなくなった部位」を自動で表示**する（例：床を濃い色に変えたら、合わない巾木・笠木に注意マーク）。
- **細かい部材は「選ばせない」**。プロのルールで自動的に決め、変えたい人だけ変更する。決める回数が大きく減る。
- 段階ごとに「後で決める」を選べるようにする（設備はショールーム見学後に決めることが多いため）。

### 2-3. ユーザー操作の流れ

```
① はじめる
   └ 物件名を入力（例：「山田様邸」）
② テイストを選ぶ
   └ 写真付きカードから1つ（ナチュラル／モダン／ジャパンディ／エレガント／ホテルライク／シンプル）
③ 外回りを選ぶ
   └ 外壁・屋根・サッシ・玄関ドア（サッシは内観色も同時に確定）
④ 床・建具を選ぶ
   └ テイスト＋サッシ内観色に合う床（◎おすすめ 3〜6点）→ 床に合う建具を ◎/○ で表示
   └ 「選択肢を広げる」で候補を増やせる
⑤ 階段を選ぶ
   └ 床・建具に合わせた候補（多くは自動で1案）
⑥ クロスを選ぶ
   └ 壁・天井・アクセント（任意）
⑦ 細かい部材を確認する
   └ 巾木・笠木・窓枠などが自動で入った状態で一覧表示 → 変えたいものだけ変更
⑧ 設備を選ぶ
   └ キッチン・浴室・洗面台・トイレの扉色・天板・パネル
⑨ まとめ
   └ 段階ごとの色見本・品番一覧・選んだ理由の一言コメント
   └ 保存 ／ 印刷（PDFは次段階）
```

各ステップの上部に「いまの組み合わせ（色見本の帯）」を常に表示し、全体の統一感を見ながら選べるようにします。

### 2-4. 画面構成

| 画面 | 内容 | MVP |
|---|---|---|
| トップ | サービスの説明、「はじめる」ボタン | ○ |
| ログイン | メールアドレスでログイン | △（MVPはブラウザ保存でも可） |
| 物件一覧 | 保存した物件のカード一覧、新規作成 | ○ |
| テイスト選択 | 写真付き6種 | ○ |
| 部位ごとの選択（床・建具・巾木・クロス） | 色見本カード、◎/○表示、「選択肢を広げる」、選んだ理由 | ○ |
| まとめ（仕様一覧） | 全部位の色見本・品番・メーカー・コメント | ○ |
| PDF出力 | 提案書 | 次段階 |
| 管理画面（Vodca用） | 商品・ルールの登録 | MVPはスプレッドシートで代用 |
| 工務店設定 | ロゴ、採用品リスト | 次段階 |

### 2-5. データ構造（どんな情報を持つか）

```
【テイスト】
  ID、名前、説明文、代表写真

【商品】
  ID、部位（床/建具/巾木/壁/天井…）、メーカー名、商品名、色名、品番、
  明度、色の系統、彩度、素材感、樹種、木目の強さ、艶、
  色見本（色コード または 画像）、テイスト適合度、状態（販売中/廃番）、
  対象の工務店（全体共通 or 特定工務店）

【配色ルール】
  ID、種類（除外/推奨/加点/減点）、対象テイスト、
  対象部位の組み合わせ（例：床×建具）、条件、点数、説明文（ユーザーに見せる理由）

【物件】
  ID、物件名、所有者（工務店/施主）、選んだテイスト、作成日、更新日

【物件の選択内容】
  物件ID、部位、選んだ商品ID、メモ

【会社（工務店）・ユーザー】 ※次段階
  会社名、ロゴ、契約プラン、所属ユーザー、採用商品リスト
```

## STEP 3：MVP 開発計画

### 3-1. MVP の目的

**「工務店の担当者が、この画面を使って施主と色決めの打ち合わせができるか」を確かめること。**
売り物の完成品ではなく、ヒアリング用の「触れる見本」です。

### 3-2. MVP に入れる機能 ／ 入れない機能

| 入れる | 入れない（後回し） |
|---|---|
| テイスト選択（6種） | ログイン・会員登録（ブラウザ保存で代用） |
| 実務の順番どおりの進行：外回り（外壁・屋根・サッシ・玄関ドアに絞る）→ 床・建具 → 階段 → クロス → 細かい部材（自動設定） | 決済 |
| ◎/○ 表示と「選択肢を広げる」 | 設備（キッチン・浴室・洗面・トイレ）は第2段階 |
| 選んだ理由の一言表示 | 室内シミュレーション画像 |
| まとめ画面（一覧）と印刷 | PDFの本格レイアウト |
| 物件の保存・一覧・編集（同じ端末内） | 工務店ごとの採用品リスト・複数人共有 |
| 架空商品データ（各部位 10〜20点） | 実在メーカー品番 |
| スマホ・タブレット・PC対応 | iPhone専用アプリ |

### 3-3. 開発工程（目安）

| 週 | 内容 | Vodca の作業 | 開発（AI）の作業 |
|---|---|---|---|
| 1週目 | ルール・データの準備 | テイスト6種の定義、ルール20〜50個、架空商品の特徴付け（テンプレートを用意します） | スプレッドシートのひな型作成 |
| 2週目 | 画面の骨組み | 画面イメージの確認 | 画面・操作の流れを作成 |
| 3週目 | 提案の仕組み | 提案結果が「プロの目で正しいか」チェック | ルールを読み込んで提案する仕組み |
| 4週目 | 保存・まとめ・見た目の仕上げ | デザインの最終確認 | 保存、一覧、印刷、デザイン調整 |
| 5〜6週目 | 工務店3〜5社で試用 | ヒアリング | 修正 |

※ Vodca 側の作業（ルール・データ作成）が最も時間を要し、全体のスピードを決めます。

### 3-4. 使う技術（MVP）

- 画面：Next.js（Web アプリ）＋ Tailwind CSS（見た目の調整）
- データ：最初はアプリ内のデータファイル（スプレッドシートから変換）、保存はブラウザ内
- 公開：Vercel（無料枠）
- → **MVP の月額費用は 0円 で始められる見込み**です。

### 3-5. 試作品で検証すべきこと（ヒアリング項目）

1. 提案された組み合わせを「プロの提案として信頼できる」と感じるか
2. 実際の打ち合わせで施主に見せて使えるか（どの場面で？）
3. 打ち合わせ時間は減りそうか（何時間 → 何時間？）
4. 自社の採用品で使えないと意味がないか（ほぼ確実に「はい」と予想）
5. **いくらなら払うか**（月5,000円／1万円／3万円、1棟あたり課金 など複数案で）
6. 誰が使うか（営業／設計／事務）
7. 今使っている他のツール（CAD、仕様決めクラウド等）との関係

## 料金プランの修正案【仮説・要検証】

| プラン | 価格案 | 内容 |
|---|---|---|
| 施主向け「テイスト診断」 | **無料** | テイスト診断と配色イメージ。集客と Vodca ブランド認知が目的 |
| 施主向け「Vodca 配色プラン」 | 9,800〜19,800円／物件 | 汎用データで全部位の組み合わせを作成、工務店に渡せる一覧表 |
| 工務店ライト | 9,800円／月 | 月3物件まで、共通データのみ |
| 工務店スタンダード | 19,800〜29,800円／月 | 物件数制限なし（※公正利用の範囲）、自社採用品リスト登録、PDF にロゴ |
| 初期設定費 | 5〜10万円 | 工務店の採用品リストを登録し、Vodca ルールで整える作業 |
| プロ監修オプション | 30,000円〜／物件 | Vodca がオンラインで最終チェック・アドバイス |

- 「無制限」は、サーバー費の面では問題ありません（1物件あたりのコストはほぼゼロ）。**問題になるのはサポートの手間**なので、上位プランで無制限、下位プランで物件数制限、という分け方が扱いやすいと考えます。
- 価格は試用のヒアリング結果で決めるのがよく、**最初の有料顧客は「先行導入価格（半額・1年固定）」**で迎えると決まりやすくなります。
