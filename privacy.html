gmail-mcp プライバシーポリシー

最終更新日: 2026年10月25日

1. 取得する情報

gmail-mcp は、利用者が許可したGoogleアカウントのGmailのメール（件名・差出人・宛先・日時・本文・添付ファイル名）を、Gmail APIの読み取り専用の権限（https://www.googleapis.com/auth/gmail.readonly）で取得します。

2. 情報の利用目的

取得した情報は、利用者自身が自分のMac上のAIアシスタントでメールを検索・要約・整理するためだけに使います。

3. 保存と共有

  • 認証情報（トークン）は利用者のMac内にのみ保存され、開発者のサーバーには送信しません。
  • メールの内容を第三者に販売・共有することはありません。
  • 広告の配信や、AI・機械学習モデルの汎用的な学習には使いません。

4. Google API サービスのユーザーデータに関するポリシーへの準拠

gmail-mcp によるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. アクセスの取り消し

利用者は Googleアカウントの「サードパーティのアクセス」 からいつでもアクセスを取り消せます。また、Mac内の ~/.gmail-mcp/tokens/ にあるファイルを削除すると、保存された認証情報も消えます。
